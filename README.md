# 🌊 Portflow (Web Frontend)

Portflow Web is the frontend client for the Portflow ecosystem. It is a highly responsive, modern web application designed to manage portfolios and workflows efficiently. Built on **Next.js 16 (App Router)** and **Tailwind CSS v4**.

---

## ✨ Features

- **🚀 Ultra-Fast Performance:** Built on React 19 and Next.js 16 for Server-Side Rendering (SSR) and seamless client-side navigation.
- **🎨 Modern UI/UX:** Styled completely with the newly released Tailwind CSS v4 for rapid, beautiful, and responsive design.
- **🪄 Beautiful Icons:** Integrated with `lucide-react` for clean and consistent iconography across the platform.

---

## 🛠️ Tech Stack

- **Framework:** Next.js (React 19)
- **Styling:** Tailwind CSS 4
- **Icons:** Lucide React
- **Language:** TypeScript

## 🚀 Getting Started

### 1. Installation
```bash
git clone https://github.com/yourusername/portflow-web.git
cd portflow-web
npm install
```

### 2. Environment Configuration
Create a `.env.local` file in the root directory to connect the frontend to the Portflow API (Backend):
```env
NEXT_PUBLIC_API_URL="http://localhost:3000"
```

### 3. Running the Application
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### 4. Build for Production
```bash
npm run build
npm run start
```
